# Лабораторна робота №4 • Варіант 5

Файли, буферизація та EOF

Автор: Гінчак Максим Богданович, 241-А.

## Завдання

- 1. Прочитати два введені користувачем файли, виділити слова, перевести в нижній регістр; надрукувати відсортовані списки та записати відсортовані спільні слова у третій файл.
- 2. Посимвольно переписати введення з консолі у файл до EOF.
- Передбачити повторний запит відсутнього вхідного файлу, запит створення вихідного, перезапис або дописування та буферизований ввід-вивід.

## Запуск в IntelliJ IDEA

Відкрийте **саме цю папку Lab04** через File → Open → New Window. Це самостійний проєкт, який не потребує сусідніх лабораторних. Оберіть JDK 17+ у File → Project Structure → Project SDK. На підготовленому Mac вже налаштовано `JBR-25-labs`.

У списку конфігурацій виберіть `Lab04_Main` і натисніть Run. Робоча тека - корінь цього проєкту.

## Запуск у терміналі

```sh
./run.sh
./test.sh
```

Скрипти беруть JDK із JAVA_HOME, установленої IntelliJ або PATH. Для Windows: створіть папку out, виконайте `javac -encoding UTF-8 --release 17 -d out src/*.java`, потім `java -cp out Main` (у PowerShell перелік файлів можна передати через `Get-ChildItem src -Filter *.java`).

## Демонстрація

1. Завдання 1: data/first.txt, data/second.txt, вихід result.txt; підтвердь створення. Спільні слова: java, код, цикл.
2. Спочатку введи неіснуючий вхідний файл, потім правильний: перевір повторний запит.
3. Завдання 2: введи текст, натисни Enter, потім Ctrl+D. Перевір українські літери у файлі.
4. Повтори для існуючого файлу: 2 дописує, 1 перезаписує.

## Уточнення умови

- Спільні слова записуються один раз; початкові відсортовані списки зберігають повтори.
- На macOS EOF - Ctrl+D; згадане в методичці Ctrl+Z, Enter стосується Windows CMD. Ctrl+Z у macOS Terminal призупиняє процес.
- Зауваження про прямий доступ «у 3 завданні» не стосується цих двох задач варіанта 5.
